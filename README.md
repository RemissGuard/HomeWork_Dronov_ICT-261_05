Создать программу вычисления указанной величины.
Результат проверить при заданных исходных значениях.

## **1. Алгоритм и блок-схема**
Алгоритм
1. Начало
2. Объявить переменные:
int x, y, z, ψ;
3. Предложить пользователю ввести значение переменных a и b:
printf("Введите значение переменных\n");
4. Принять введенные значения переменных a и b:
scanf("%lf\n",&x);
scanf("%lf\n",&y);
scanf("%lf",&z);
5. Записать формулы вычисления переменной ψ:
ψ = fabs(pow(x,y/x)-pow(y/x,(float)1/3))+(y-x)*((cos(y)-z/(y-x))/(1+pow(y-x,2)));
6. Вывести результаты расчетов на основе введенных данных с подстановкой всех значений в текст.
printf("\nОтвет: %5.4lf\n", ψ);
7. Конец

## **2. Реализация программы**
```
#include <stdio.h>
#include <locale.h>
#include <math.h>
main()
{
	setlocale(LC_ALL, "RUS");
	double x, y, z, ψ;
	printf("Введите значение переменных\n");
	scanf("%lf\n",&x);
	scanf("%lf\n",&y);
	scanf("%lf",&z);
	ψ = fabs(pow(x,y/x)-pow(y/x,(float)1/3))+(y-x)*((cos(y)-z/(y-x))/(1+pow(y-x,2)));
	printf("\nОтвет: %5.4lf\n", ψ);
}
```
